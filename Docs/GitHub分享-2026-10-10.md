## 分享内容

仓库保存 Unity 源码、场景、材质、模型、`.meta`、Packages 和 ProjectSettings，同时包含 Blender 可编辑美术源文件、制作 / 构建工具、实际游戏截图与开发记录。根目录 `README.md` 为仓库首页，介绍启动方式和操作。

Unity 缓存、构建输出、工具下载、登录配置和本机日志通过 `.gitignore` 排除。当前资源可以直接通过普通 Git 上传；未引入 Git LFS。

## 在另一台电脑打开

```powershell
git clone https://github.com/tongmu1633/island-voyage.git
```

使用 Unity Hub 添加克隆目录中的 `IslandVoyage` 子目录，安装 Unity 6000.6.3f1，等待依赖和资源导入，打开 `Assets/Scenes/IslandVoyage.unity` 并运行。Web 构建需要对应的 Web Build Support 模块。`ArtSource` 中的 `.blend` 可用 Blender 5.2 LTS 编辑。

## 后续更新

在本机项目根目录执行：

```powershell
git status
git add .
git commit -m "说明本次修改"
git push
```

提交前通过 `git status` 核对修改。每次更新保持 Unity 的 `.meta` 与对应资源一起提交。已设置 `main` 跟踪 `origin/main` 后，后续可以直接使用 `git push`。

当前电脑使用 GitHub CLI 2.102.0 完成官方设备登录，授权保存于 Windows 凭据库。此项目的 Git 凭据助手在本地 `.git/config` 中指向工作区已忽略的 CLI 与登录配置目录；这些配置不上传到仓库。提交作者使用 GitHub 提供的匿名邮箱。若移动本机项目目录，应重新配置本地登录工具路径；在其他电脑克隆后可使用自己的 GitHub 登录方式。

本次分享保存源码与素材；Windows / Web 构建继续保留在本机 `IslandVoyage/Builds/`。
