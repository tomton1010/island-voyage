# 海岛游船小游戏开发进度

记录时间：2026-10-04，北京时间。版本：**0.2.0**。

本轮完成 Blender 模型与骨骼动画升级。用户已取消“整体风格接近最初海岛参考图”的约束，后续以更自然的比例、细化模型、材质和画面观感为目标。此前记录在 `Docs/开发进度-2026-10-02.md`。

## 本轮成果

- **34 个 Blender 模型**已保存为可编辑 `.blend`，导出 FBX 并实际接入 Unity。源文件保存了彩色模型视角，打开后可直接查看顶点绘色。
- 小船细化曲面木板船壳、接缝、内侧肋骨、座椅、木地板、储物箱、系缆桩、绳圈、索具、独立舵和操纵杆。3 骨骼船帆进行小幅风摆，帆架角度随相对风向调整。
- 鲸鱼、鲨鱼、海豚改为连续蒙皮，细化吻部、鳍、尾、眼睛、口线、鳃裂及鲸鱼腹沟。鲨鱼横向摆尾；鲸鱼、海豚上下摆尾，动作逐渐传到尾柄和尾鳍。海豚跃起时混合 Glide 动作，根节点保留重力轨迹。
- 8 鱼种改为 Blender 模型，保留各自体型、花纹和鳍。所有实际活动鱼使用 7 骨骼 Swim 动作，游动频率随速度调整。
- 3 个居民模型供 6 名岛民使用，增加五官、头发/帽子、衣服、手指和鞋。20 骨骼的 Walk、Idle、Wave 包含支撑期、抬脚、反向摆臂和重心变化，步频按实际速度 / 0.639 调整，渐变切换动作。
- 棕榈树细化弯曲树干、树皮环、细叶片和 13 骨骼轻微风摆。木屋细化木瓦、百叶窗、木框、门、廊架与栏杆；码头细化木板、钉头、支撑和缆绳。
- 制作 5 类珊瑚园、3 类岩石，以及灌木、长椅、公告板、贝壳和海星。减少珊瑚密度并改变各类组合，给浅水区留出空隙。
- 使用 URP 光照材质、适度粗糙度、木纹细节、接触阴影、ACES 色调映射、轻微辉光与暗角；调整海水深浅色、视角反射与细小波纹。
- 修复 FBX 正向相反、居民骨盆位移坐标、招手方向及手腕/脚踝衔接。补齐渲染器后期效果资源引用，使色调配置实际启用。
- 近景复核后修复管状网格在膝盖、手肘处的截面翻转：改用平行运输坐标框架，增加端部支撑环，连续混合前臂与手部权重。大型动物眼睛和口线按实际体表截面定位，避免埋入体表。

## 保留的玩法与物理

WASD 航行，Shift 慢行；点击鱼群驱散，慢速靠近后 E 撒网。实际速度 ≥4 米/秒、距离鱼群 ≤8 米会惊扰；速度 ≤2 米/秒、距离平静鱼群 ≤5 米可捕鱼。每次有效尝试独立判定 20% 成功率，失败惊散鱼群，成功减少一条鱼并记录鱼获。

航行范围 520×440 米、7 座岛屿、8 鱼种、40 群。大型动物低频偶遇，同时最多 2 只，初始没有常驻大型动物。6 名居民分布在 3 座岛上。

船保留 320 千克刚体、四点浮力、共享海面波高、水阻、受限推进与转向。尾流、岸浪、缩放、昼夜、暂停、海景模式及鱼获记录保留；鱼获尚无跨次运行存档。

## 精度与后续空间

目前为风格化实时游戏画面。水面、尾流和行为使用游戏物理近似，没有完整流体、肌肉或布料碰撞求解，也未使用动作捕捉或影视级扫描。居民动作按速度匹配步频，不保证复杂斜坡上的每一步严格锁脚。

地形、海水、海草、部分小道具与粒子仍由 Unity 生成，主要模型已使用 Blender。旧程序建模函数保留在部分代码中，但不再负责船、鱼、动物、居民与主要岛屿装饰的显示。

尚未进行长时间性能基准、手机或多个桌面浏览器的兼容性验收，不承诺稳定 60 FPS。后续可打磨近景人物、材质纹理、海岸细节、镜头构图与性能。

网页版 URP 17.6.0 会记录一条 `Blit FSR Upscaling` 的 Shader 不支持警告。查阅项目安装的 URP 源码后确认它来自 FSR 材质初始化；该通道返回无效并跳过执行，不会禁用独立的 Bloom 和 Uber 色调通道。当前渲染比例为 1、未启用 FSR，游戏仍正常渲染；暂保留原始日志，未修改官方包或屏蔽警告。

## 常用命令

从工程根目录执行，同一工程不要同时运行两份 Unity 编辑器或构建。

```powershell
.\Tools\Invoke-Unity.ps1 -Task Windows
.\Tools\Invoke-Unity.ps1 -Task Web
.\Tools\Test-Voyage.ps1
.\Tools\Preview-Voyage.ps1 -Scene Sailing
.\Tools\Preview-Voyage.ps1 -Scene Night
.\Tools\Preview-Blender.ps1
python .\Tools\serve-web.py
```

Blender 再生成命令见 `ArtSource/README.md`。生成器会重写同名源文件和 FBX；手工修改前先另存副本，或将修改同步进生成脚本。
