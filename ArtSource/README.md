# Blender 美术源文件

2026-10-03：取消“接近最初参考图”的限制，转向自然比例、细化材质、电影色调和连贯的骨骼动作。模型为本项目自行制作的实时游戏资产。

`Blender/` 包含 34 个可以直接在 Blender 5.2 LTS 中打开和修改的 `.blend` 文件。对应 FBX 在 `IslandVoyage/Assets/Resources/Blender/Models/`，Unity 运行时直接实例化这些资源。

打开 `.blend` 后，在 Animation 工作区的 Action 编辑器选择具名动作；动作也保存在 NLA 轨道中。NLA 轨道静音是为了避免动作与当前 Action 重复叠加。查看骨骼可选择 Armature，进入 Pose Mode；网格顶点组可在 Weight Paint 中编辑。

模型使用米制。作者坐标为 Unity 的 X、Y 向上、Z 向前；生成器转到 Blender 的 Z 向上，FBX 导入器负责轴转换。`ModelForward` 标记用来验证导入后的实际正向和比例。不要删除该标记再运行自动验证。

2026-10-08 小船升级至 18,367 顶点 / 32,544 三角形；地板顶面位于船体本地 Y=0.26 米，四点浮力探针调整到 Y=-0.34 米。`BoatController` 每帧向水面传递船体逆矩阵，`VoyageWater.shader` 使用同一船壳截面排除船内海水。若再修改船壳尺寸，应同时更新水面排除形状和浮力探针。旧 `.blend`、FBX、统计与生成脚本保存在 `Backups/2026-10-08-Sailboat/`。其余 33 个模型保持现有资源。

动作设计：鲨鱼横向摆尾；鲸鱼和海豚上下摆尾，摆动从躯干逐渐传到尾柄与尾鳍。居民采用有支撑期和抬脚期的步态、反向摆臂、轻微重心转移，运行时以实际速度 / 0.639 调整步频并渐变切换动作。船帆与树叶是小幅蒙皮风摆；海豚跃出水面时混合 Glide，根节点仍按重力轨迹移动。

0.4.1 运行时调帆修复：Unity 的 FBX 导入保留了内层 `Sailboat` 节点约 90° 的 X 轴转换。帆与舵应绕父节点坐标中转换后的船体竖直轴旋转，不能直接使用本地 Y 轴。调帆中心位于船体坐标 `(0, 1.03, 0.20)`，保持桅杆附件位置；保留骨骼 Wind 动作。若修改桅杆位置，应同步更新 `BoatController` 的调帆中心。

## 再生成与验证

0.5.0 钓手复用 Blender 的 `Resident0` 蒙皮资源，运行时停止原居民循环动作，按抛竿、等口、提竿、搏鱼、起鱼和收竿阶段平滑驱动坐姿、身体与鱼竿。双臂使用两段骨骼 IK 连接握柄和卷线器；鱼竿按负载弯曲，浮漂随共享海面采样起伏，抛投按重力轨迹运动。钓具和船尾坐凳由 Unity 生成，未增加新的 `.blend` 文件，资源总数仍为 34。坐凳位置和 IK 目标位于 `FishingPresentation.cs`，修改居民骨架或船尾甲板后需重新运行钓鱼运行检查。

普通鱼模型和 Swim 动作继续使用原资源。运行时将礁区鱼下沉约 1.4–2.7 米、外海鱼下沉约 2.65–3.85 米，并向 `BlenderSurface.shader` 传递每条鱼实际水深，模拟随深度与观察距离变化的吸收和衰减。真实上钩鱼由鱼群中保留的一条鱼表现，游泳动作保持连续，起鱼离水时颜色随实际水深恢复；没有另造替身鱼。

在工程根目录运行：

```powershell
& 'E:\Blender\blender-5.2.2-windows-x64\blender.exe' --background --python '.\Tools\Blender\build_assets.py'
& 'E:\Blender\blender-5.2.2-windows-x64\blender.exe' --background --python '.\Tools\Blender\validate_motion.py'
.\Tools\Invoke-Unity.ps1 -Task Windows
```

生成器会重写同名 `.blend` 和 FBX；如果已手工修改，请先另存副本，或将修改同步回生成脚本。`AssetReport.json` 是几何与骨骼统计，`MotionValidation.json` 是动作循环与居民脚部高度检查。Windows 和 Web 构建都会检查全部 34 个模型的材质、轴向、权重和实际蒙皮变形。

地形、海水、海草、尾流和粒子仍由 Unity 程序生成；船体浮力与碰撞、鱼群行为和居民行走控制仍由 Unity 负责。没有使用动作捕捉、影视级扫描资产、完整布料或流体求解。细节和动作均为适合游戏实时运行的近似。
