# 潮汐群岛 · Island Voyage

一个 3D 海岛游船游戏原型。2026-10-03 起取消最初参考图的风格限制，使用 Blender 自制的 34 个细化模型、真实骨骼蒙皮动作与 URP 材质。地形、水面、钓具、涟漪和环境音由 Unity 生成；中文字体使用 Noto Sans CJK SC，字体许可随工程附带。

## 打开与游玩

游戏版本：**0.5.1**。开发环境：**Unity 6000.6.3f1**，URP 17.6.0。默认使用近景第三人称镜头，左上角为群岛小地图，右上角显示天气与海上奇遇；船尾有坐姿钓手。

1. 在 Unity Hub 的“项目”页面选择“添加磁盘上的项目”，选中本 README 所在的 `IslandVoyage` 文件夹。
2. 等待官方依赖和字体导入完成。
3. 首次导入会生成 `Assets/Scenes/IslandVoyage.unity` 场景和 URP 设置。必要时从菜单选择 `Tools > Island Voyage > Prepare Project`。
4. 打开该场景，按编辑器上方 Play 运行。海岛和动物在进入运行模式时生成，因此编辑模式下启动场景仅包含启动器。

Windows 构建生成后，打开 `Builds/Windows/IslandVoyage.exe` 即可游玩。保留同目录下的数据文件夹和 DLL，复制给别人时应复制整个 Windows 文件夹。

## 操作与规则

| 操作 | 效果 |
| --- | --- |
| W / S | 沿船头前进 / 沿船尾倒航；保留加减速惯性，倒航前会先减速 |
| A / D | 左 / 右转舵；船动起来后产生转向，倒航时舵效反转 |
| Shift + W/S | 慢行；减速需要少量时间 |
| 鼠标左键点击鱼群 | 未钓鱼时，鱼群受惊并逃散 |
| E | 慢速靠近平静鱼群后抛竿；浮漂明显下沉、出现咬钩提示后再次按 E 提竿 |
| 按住空格 / 鼠标左键 | 上钩后收线；松开泄力，保持张力在绿色区附近 |
| Q | 收竿、取消当前钓鱼 |
| P / Esc | 暂停或继续；网页版可使用界面上的暂停按钮 |
| 查看鱼获 | 查看本次航行按鱼种记录的捕获数量 |
| 声音 | 开关程序生成的环境音和反馈音 |
| 鼠标滚轮 / + / − | 平滑拉近、拉远跟随镜头，水平距离 8–24 米 |
| 鼠标右键按住并拖动 | 环绕小船，左右调整方位、上下调整观察角度；松开后保留视角 |
| C | 恢复船尾默认方位、俯视角度及 11.5 米跟随距离 |
| T / 时间按钮 | 切换昼夜流速：1×、4×、12×、暂停时间 |
| Y / 切换天气 | 依次体验晴朗、多云、降雨、海雾、雷暴；海况渐变 |
| N / 自然奇遇 | 依次触发大鱼群迁徙、荧光海、异常涌浪，先出现预告 |
| H | 隐藏、恢复界面，进入纯海景模式 |
| B | 打开、关闭鱼获记录 |

- 最高航速 6 米/秒，慢速阈值 2 米/秒，高速阈值 4 米/秒。
- 倒航目标上限 2.5 米/秒；Shift 慢行目标 1.85 米/秒。W/S 的推进方向始终跟随船体，镜头朝向不会改变控制方向。
- 高速进入鱼群 8 米警戒范围会吓跑鱼群。
- 低速或停船，进入平静鱼群 12 米范围可抛竿；距离按船体边缘到最近的一条鱼计算。抛竿检查岸线遮挡，不会把饵投到岛上。
- 抛竿约 1.25 秒；浮漂按重力轨迹入水。等口约 3.5–7.2 秒，随后先有约 1 秒试饵，正式咬钩窗口 1.35 秒。试饵时不要提竿；浮漂明显下沉、出现咬钩提示时按 E。
- 上钩后按住空格 / 左键收线，松开泄力。鱼会周期性冲刺，不同鱼种的耐力、冲刺强度和收线难度不同。张力过高持续约 0.65 秒会断线，过低持续约 2.1 秒会脱钩；持续不处理最长 75 秒结束。及时提竿并控制张力可稳定成功，替换旧的固定 20% 判定。
- 鱼被拉近至约 2.4 米且耐力低于 12% 后，约 1.6 秒提鱼入船；完成后才记录 1 条鱼与重量。每种鱼记录本次航行最大重量。
- 失败会惊扰鱼群；Q 主动收竿可平静取消。收竿过程约 0.9 秒，整理钓具约 1.2 秒。航速超过 2.2 米/秒、线距超过 21 米或目标离开活动水域时收竿中断。钓鱼时左键用于收线，不同时驱散鱼群。
- 暂停、鱼获弹窗冻结钓鱼计时；钓鱼时切换应用会自动暂停，返回后按 P 或继续按钮恢复，避免错过鱼口。日夜倍率不改变咬钩窗口或控线物理。
- 鱼群在威胁解除后回到巡游状态；捕获减少的鱼只会在船离开后逐渐补充。
- 含 8 种普通鱼，共 40 个鱼群；每群 10–18 条，初始鱼群为 13 条。鱼群活动半径约 5.5–9.5 米，按浅礁和外海栖息区域分布。
- 礁区鱼自然深度约 1.4–2.7 米，外海鱼约 2.7–3.9 米，个体缓慢上下游动，最低不低于海床上方约 0.45 米。水下材质按水深、观察角度和距离衰减颜色与细节，较深的鱼更隐约；上钩鱼逐渐拉到水面后恢复清晰。普通鱼不再投出夸张的海床阴影，小地图仍可用于找鱼。
- 大型动物改为偶遇：鲸鱼、鲨鱼或 1–2 条海豚从视野外进入水域，同一时刻最多激活 2 只。首次约 45 秒后尝试生成，之后间隔约 90–145 秒；航线和观察方向会影响能否遇见。鲸鱼出现概率较低。
- 大型动物用于观察，钓鱼针对普通鱼群；它们不再持续追逐或环绕小船。

鱼获数量和最大重量目前只保存于本次运行，没有跨次运行存档。

## 钓鱼动作

船尾钓手复用 Blender `Resident0` 的真实蒙皮骨骼，坐在后甲板新增钓位，保持与船体同步起伏。分层坐姿、抛竿摆臂、提竿和收鱼姿势由运行时驱动；双臂两段 IK 把双手约束在竿柄及线轮附近。原有船帆、居民和动物模型保持不变，总计仍为 34 套 Blender 资源。

碳色鱼竿带软木手柄、线轮、导环与转动摇柄，受张力弯曲；线从竿尖连续连接浮漂，上钩时子线连接真实鱼的嘴部。等待时浮漂随海浪起伏，试饵时轻抖，咬钩时明显下沉；鱼有真实的游泳骨骼动作，上钩后从深水逐渐拉近并提到船上。当前鱼竿和鱼线使用连续曲线及张力近似，未实现完整弹性杆或绳索碰撞求解。

## 船舱、天气与自然事件

小船使用重新制作的 Blender 船壳与贴合船舱的抬高木地板，补充前后甲板、储物舱、龙骨、船首金属件和紧固细节。浮力吃水随之调整，水面 Shader 按船体位置、俯仰、横摇和船壳截面排除船内海水，解决海面穿过座椅与船舱的问题。可编辑源文件为 `ArtSource/Blender/Sailboat.blend`；上次模型和生成脚本备份在 `ArtSource/Backups/2026-10-08-Sailboat/`（均位于工程上一级）。

船帆绕桅杆的船体竖直轴随风调节，帆顶保持连接桅杆，小幅风摆由原有骨骼动画负责。0.4.1 修复了 FBX 内层父节点 90° 坐标转换导致本地 Y 轴实际向前的问题；帆与舵保留导入姿态，并使用转换后的船体竖直轴旋转。

五类天气自动轮换：初次约 210 秒，之后间隔 180–360 秒。云量、日照、雨量、雾和浪高逐渐变化；风对小船施加空气阻力，近岸风力减弱。雨滴受下落速度、重力和风影响，粒子池上限 1,600。雷暴包含远处闪电和按距离 / 343 米每秒延迟的雷声；声音按钮同时控制天气音效。海雾能见度约 65 米，晴天远海约 270 米。CPU 浮力与 GPU 海面共享天气浪高和移动涌浪参数。

自然奇遇首次约 65 秒尝试出现，之后有 115–215 秒的冷却；启动前有 8 秒提示。按 N 可主动体验，并结束上一个事件。迁徙需附近存在宽度足够的安全航道；水域过窄时不会强行生成，可到开阔海面再触发。

| 事件 | 行为 |
| --- | --- |
| 大鱼群迁徙 | 8 个鱼种、8 群共 144 条额外鱼，沿检查过的水域连续游过；骨骼游泳、加速、转向和避岸继续生效，可被惊扰或钓获，使用同一控线机制；航图显示青色标记。约 75 秒，进出逐渐显隐，复用有限模型池。 |
| 异常涌浪 | 32 秒事件窗口，移动浪脊高约 1.35 米，叠加当前天气海浪；实际影响船体浮力与鱼群惊扰，近岸浪高衰减。预告后可按 Shift 减速并靠近岛岸避浪。 |
| 荧光海 | 约 55 秒；夜间海面局部、岸边浪花和船的尾流发出蓝绿光，白昼抑制光芒；自然调度在夜间选择此事件。 |

事件结束后有 10 秒消退阶段并清理临时效果。日夜时间倍率不会加速天气、鱼群或重力；暂停游戏和鱼获弹窗会冻结天气及事件计时。当前灾难以环境和操船影响呈现，未加入船体损坏、沉船或永久丢失鱼获。

## 新地图、昼夜与物理

航行边界扩展为 **520×440 米**，含 7 座岛屿。主岛和另外两座岛上共有 6 名居民，会行走、停留，遇到障碍会调整路线。

0.5.1 将海岛不规则岸线、地形碰撞和海床高度统一，岸坡连续下降到外海 4.5 米深的海床。珊瑚底座、海草根部、礁石和沙滩物件按实际地形摆放，过浅位置不生成露出水面的高珊瑚。小屋下方有连接地面的基座，门廊、楼梯及码头支柱延伸到地面或海床，码头岸端与沙滩衔接。

普通鱼、上钩鱼和迁徙鱼使用实际海床高度维持间距；迁徙规划检查整条鱼群航道的水深。鲸、鲨、海豚按实际骨骼动作测量海床间距，离场逐渐淡出，鲸鱼在呼吸孔露出水面后喷气。水下对象随深度吸收颜色，离水部分恢复正常颜色，海床阴影随深度减弱。海面保留近处 1.25 米网格，以外环延伸到 640×640 米，覆盖远海完全雾化的区域。

近景透视镜头跟在船尾后方，平滑追随船头朝向并保持水平线稳定；近岸或建筑遮挡时缩短跟随距离。左上角小地图保持北向朝上，显示七座岛屿、船位及船头箭头、40 个鱼群与当前出现的大型动物。白色箭头为小船，黄色点为平静鱼群、红色点为受惊鱼群，浅蓝点为大型动物；较大的鱼群标记表示当前附近鱼群。地图底部显示航向和世界坐标。点击小地图不会驱散鱼群。

按住鼠标右键拖拽可环绕船体；松开后保留相对船头的观察方位，小船转弯时视角仍跟随。观察高度限制在 12°–65°，镜头继续平滑移动、避开海面与地形并保持水平线稳定。拖拽不会改变 W/S 的船体方向控制，也不会驱散鱼群；从小地图或按钮上开始的拖拽不会转动镜头。失焦、暂停或鱼获弹窗会终止当前拖拽；C 一次恢复方位、观察高度和缩放。网页游戏区域已禁止右键菜单弹出。

默认从 09:30 开始，1× 流速下完整昼夜周期为 20 分钟。T 只改变太阳与时钟的推进速度，船、鱼、重力和海浪维持原来的物理时间。暂停游戏或打开鱼获记录会冻结世界与船体物理。

小船采用 320 千克刚体、四点浮力、水阻、推进力、舵的角速度限制和岸边碰撞。海面与浮力采样共享三组波，波频率采用重力色散关系；岸边浪与泡沫用浅水浪的视觉近似。尾流按约 19.5° 的深水尾波半角展开并随时间消散。海豚跃出水面后按 9.81 米/秒² 重力落回海中，并切换舒展动作；鲸类上下摆尾，鲨鱼横向摆尾，身体随骨骼连续变形。居民使用角色碰撞器与重力，Blender 步态包含支撑期、抬脚、摆臂和重心变化，步频随实际速度调整。

Blender 可编辑源文件在上一级 `ArtSource/Blender/`，制作与再生成说明见 `ArtSource/README.md`。Unity 的导入设置、材质映射和骨骼变形检查由 `BlenderArtPipeline.cs` 管理。

这是实时游戏中的物理近似。水面不进行完整流体求解，帆布没有布料碰撞求解，鱼群和大型动物使用受加速度与转向限制的行为模型；精度不等同于工程仿真。

远海逐渐融入与昼夜天空匹配的雾色，减轻近景镜头下的海天色带。船行尾流随实际移动方向展开，倒航时方向相应改变。

## 网页版

Web Build Support 已安装后，可用菜单 `Tools > Island Voyage > Build Web` 构建。网页构建需通过 HTTP 服务运行，不能直接双击 `index.html`。

在工程上一级目录执行：

```powershell
python .\Tools\serve-web.py
```

然后用桌面 Chrome 或 Edge 打开 `http://127.0.0.1:8765`。点击游戏画面使其获得键盘焦点。关闭窗口或切换应用后，按键不会残留。该服务只监听本机，不会发布到公网。

## 构建和验证

菜单 `Tools > Island Voyage > Validate Fishing Rules` 检查速度、距离、鱼群状态和冷却边界；八种鱼在 50 fps 与 10 fps 时间步下均验证正确控线可成功、持续收线断线、持续松线脱钩。

上级目录的 PowerShell 辅助脚本：

```powershell
.\Tools\Invoke-Unity.ps1 -Task Windows
.\Tools\Invoke-Unity.ps1 -Task Web
```

脚本使用当前安装位置 `E:\Unity\Editors\6000.6.3f1\Editor\Unity.exe`；若移动 Editor，需要修改辅助脚本中的路径。运行时不要让另一份编辑器占用同一工程。

Windows 包接受开发验证参数 `--self-test`，检查透视镜头构图、船尾跟随、水平线、缩放与近距离避障；任意船头角度下的前进/倒航、A/D 转向及位置重置；小地图船位、航向、边界和鱼群数量。同时检查鱼群分布、稀有动物上限、昼夜照明、浮力、航速、减速、正向/倒航尾流、暂停、捕鱼分支和岛屿阻挡。此模式完成后自动退出，不用于日常游玩。

0.4.0 自检增加干燥船舱、水面排除矩阵、天气渐变、真实雨粒子、雾范围、风浪联动、闪电与雷暴浮力、迁徙游动/捕捉/惊扰/对象池回收、涌浪预警与 CPU/GPU 参数、荧光昼夜抑制。相机额外通过同一指针输入处理函数验证拖拽、松开保留、UI 起点阻挡、失焦取消和角度边界，并检查实际侧面视角、水平线、环绕时仍沿船头前进、C 复位。

0.5.0 自检增加实际鱼深与水下材质、真实抛竿空中轨迹、手柄约束、鱼线显示、暂停冻结、试饵与咬钩、按时提竿、真实鱼预留、控线收鱼、单次入账与重量、提前提竿失败及清理检查。

0.5.1 自检增加 `VOYAGE_ENVIRONMENT_TESTS_PASSED`：直接采样地形碰撞器与渲染网格，检查珊瑚 / 海草接地、建筑基座、海面覆盖和顶点预算；验证鱼群海床间距、动物离场淡出、鲸鱼水上呼吸及海豚重力轨迹，并烘焙实际导入模型的完整 Swim / Glide 动作检查海床穿模。原有运行与钓鱼检查继续执行。

`--capture <绝对PNG路径>` 使用 URP 离屏渲染保存 1600×900 的真实场景，解决隐藏窗口无法截屏的问题。普通启动约 3 秒后截图；`--capture-delay 12` 延迟截图，自检模式在检查完成后截图。`--scenic` 隐藏界面，`--hour 21` 指定预览时段，`--sailing` 用于航行效果预览，`--preview-quit` 截图后退出。日常游玩无需这些参数。

上级目录的 `Tools/Preview-Voyage.ps1 -Scene Sailing` 和 `-Scene Night` 可保存航行与夜景预览。

`-Scene Cottage` 保存近岸小屋和码头支撑视角，`-Scene Offshore` 保存低角度远海视角。开发截图可使用 `--boat-position 35,-13`、`--view-yaw -20`、`--view-elevation 18`、`--view-distance 24` 设置船位和镜头；普通启动无需这些参数。

`Tools/Preview-Voyage.ps1 -Scene Fishing -ShowHud` 使用 `--fishing-demo` 自动演示同一抛竿、提竿及控线逻辑，并从侧面保存钓鱼场景。演示不会在普通启动或网页版中自动操作。

也可使用 `-Scene Rain|Fog|Storm|Migration|Swell|Luminous -ShowHud` 保存对应实际场景。Windows 开发预览参数 `--weather Rain|Fog|Thunderstorm`、`--event Migration|RogueSwell|LuminousSea` 直接进入稳定状态供截图；日常 Y/N 交互仍采用渐变和预告。

`Tools/Preview-Blender.ps1` 拍摄实际 Unity 导入模型，并在安装了 ffmpeg 时生成海豚与居民骨骼动画的 GIF 和 MP4。可编辑 Blender 源文件和再生成说明位于上级目录 `ArtSource/README.md`。

代码入口：`Assets/IslandVoyage/Scripts/GameBootstrap.cs`；钓鱼阶段与交互：`FishingController.cs`；控线与耐力：`FishingFight.cs`；钓手 IK 与钓具：`FishingPresentation.cs`；速度和抛竿阈值：`VoyageRules.cs`；场景搭建：`WorldBuilder.cs`；Blender 资源加载与动画：`BlenderAssets.cs`；导入验证：`Assets/IslandVoyage/Editor/BlenderArtPipeline.cs`。模型生成脚本位于上级目录 `Tools/Blender/`。地形、水面、海草及少量道具仍由 `Geometry.cs` 等生成，旧主要模型创建函数已不用于实际显示。
